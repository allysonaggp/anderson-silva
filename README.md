# 🧑‍💼 Anderson Silva – Site Institucional

Este projeto é um site institucional desenvolvido com HTML e CSS para apresentar os serviços, perfil profissional e formas de contato de Anderson Silva. O objetivo é oferecer uma presença online clara, elegante e responsiva.

---

## ✨ Funcionalidades

- 🧑‍💼 Página de apresentação profissional
- 📄 Seções sobre serviços, experiência e contato
- 📱 Layout responsivo para dispositivos móveis
- 🎨 Estilo visual limpo e moderno
- 📷 Imagens ilustrativas e identidade visual personalizada

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – estrutura semântica das páginas
- **CSS3** – estilização e responsividade
- *(Sem uso de JavaScript ou frameworks)*

---

├── style.css            # Estilos personalizados
